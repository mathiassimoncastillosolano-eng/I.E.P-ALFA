# I.E.P. ALFA — Sistema de Gestión Escolar

Frontend con datos mock (React + Vite + TypeScript + Tailwind). Proyecto base (scaffold).

## Arranque
1. `npm install`
2. Pega tu Master Prompt completo en `docs/MASTER_PROMPT.md`.
3. `npm run dev` para ver la pantalla provisional; `npm test` para las pruebas de finanzas.
4. Abre Claude Code en esta carpeta y usa el prompt corto de `docs/ARQUITECTURA.md` (sección 2.2).
